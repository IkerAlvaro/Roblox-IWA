Roblox IWA

Roblox en ChromeOS

Isolated Web App local. Se abre como aplicación independiente, no como pestaña de chrome:// con el dominio bloqueado.

Si la red del centro o el DNS bloquean roblox.com, esta app tampoco podrá conectarse. Un IWA no salta filtros de red ni políticas de administrador.
